# Indian Mini Truck | 3D Blender Project

A 3D modelling experiment focused on creating a stylized Indian mini cargo truck inspired by traditional Indian commercial vehicles.

**Created by Kunal Bhiwania**

## Project Overview

This project explores 3D modelling and visualization of a compact Indian mini cargo truck inspired by the Tata Ace / Chhota Hathi category.

The concept combines recognizable Indian mini-truck proportions with traditional Indian truck-inspired visual design.

## Project Details

- 3D modelling using Blender
- Compact Indian mini cargo truck concept
- Stylized vehicle proportions
- 3D visualization and modelling experiments

## Software & Tools

- Blender
- 3D Modelling
- 3D Visualization

## Project File

The original Blender project file is included in this repository.

Download the `.blend` file directly from the repository to explore the 3D model.
